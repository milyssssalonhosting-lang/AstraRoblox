# codex_assets

Carpeta de entrega para **ChatGPT Codex** (Astra): aquí deja assets y diseños
(imágenes PNG de íconos/UI, modelos `.rbxm`/`.fbx`/`.obj`, bocetos, paletas, ideas).

Claude los revisa desde aquí y los integra al juego en Roblox Studio.

## Reglas
- Una subcarpeta por pedido, por ejemplo `codex_assets/2026-10-22_iconos-mascotas/`.
- Dentro, un `NOTAS.md` corto: qué es, para qué parte del juego y tamaño sugerido.
- Estilo del juego: muy colorido ("dopamina"), caricatura, bordes gruesos oscuros,
  letra redonda gruesa (ver `investigacion/GUIA_ROBLOX.md`).
- Nada copiado de otros juegos (Pet Simulator, Fortnite, etc.) ni con marcas.
- Modelos `.rbxm`: sin scripts dentro (Claude igual los audita antes de usarlos).
